# CV application practice PDFs

These print resources accompany the English CV toolkit at https://jobpick20.com/guides/uae-cv-guide/.

- `jobpick-fictional-cv.pdf`: one-page fictional teaching CV, not a real applicant's history.
- `jobpick-cv-application-workbook.pdf`: three-page blank handwriting workbook, not a ready-to-submit CV or a fillable form.

Both PDFs are built from the corresponding sections in the guide by `python scripts/build-cv-workshop-print.py` (requires Python reportlab and beautifulsoup4). Keep the fictional labels, privacy prompts and source-to-PDF consistency intact. Check pagination and extraction order after rebuilding. Do not replace these with a real person's application data.
