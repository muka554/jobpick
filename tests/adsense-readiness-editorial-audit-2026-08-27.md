# AdSense-readiness editorial audit — 27 August 2026

## Purpose and scope

This audit identifies evidence-based website improvements that can strengthen JobPick’s AdSense-readiness. It does **not** establish eligibility, approval, review outcome, traffic quality, account ownership, or legal compliance. Google’s final review is account-side and policy-dependent.

## Confirmed strengths

| Area | Evidence observed | Readiness value |
|---|---|---|
| Editorial scope | Sitemap contains 20 substantive city and guide routes; each has an editorial-team byline. | Distinguishes publisher guidance from the interactive directory. |
| Advertising scope | AdSense code is restricted to the 20 substantive city and editorial guides, not the homepage search hub, filters, platform directory, tracker, account flows, or sign-in screens. | Avoids placing ads on a navigation and behavioral tool. |
| Privacy and consent | The Privacy Policy describes the current Google consent message and scoped advertising behavior. The AdSense European-regulations message was published with Consent, Do not consent, and Manage options paths. | Provides a documented consent route for relevant traffic. |
| Publisher transparency | The Editorial Team page identifies Middle East Job Hub as publisher, explains JobPick as the search experience, describes source review, and links to the corrections route. | Provides baseline editorial ownership and correction information. |
| Source practice | Existing substantive guides show a team byline, visible review date, and official-source cards. | Supports transparent public-information guidance. |

## Priority gaps identified

| Priority | Evidence-based gap | Recommended improvement |
|---|---|---|
| P0 | Saudi Arabia has a Riyadh city page but no country-level Saudi job-search guide in the sitemap. | Publish a distinct, source-backed Saudi guide with a clearly different reader question from the Riyadh city page. |
| P0 | The current author page describes the editorial team but does not provide a detailed individual biography, credential, or verifiable professional history. | Strengthen the organization-team profile and guide bylines without inventing individual claims. Add an individual editor page only after the owner supplies factual biography information. |
| P1 | The existing correction policy is clear but has no dedicated public corrections record. | Add a transparent corrections-log section or a dedicated log that publishes material amendments without implying perfect coverage. |
| P1 | The Privacy Policy links to Google’s general data-responsibility page but does not state in plain present tense that Google and other providers may use cookies to serve and personalize ads based on prior visits, nor does it link directly to Google Ads Settings. | Make this narrowly scoped disclosure current and link users to Google’s Ads Settings and data-use page. |
| P1 | Existing guide source cards are useful but their structure is not formalized as one reusable “Sources and review” module. | Add a concise reusable module to every substantive guide and create it for the Saudi guide from the outset. |
| P2 | The AdSense-native message is currently configured with English as default and no additional message languages selected. | Add Arabic, Hindi, and Urdu variants in AdSense if the platform provides them; this is a configuration enhancement, not a claimed policy prerequisite. |

## Explicit non-actions

This audit does not set a numerical article target as if Google imposed one, create traffic, manipulate clicks or impressions, make legal eligibility determinations, collect personal credentials, or represent the site as AdSense-approved.
